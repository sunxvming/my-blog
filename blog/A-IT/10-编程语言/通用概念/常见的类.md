
## 数据处理类
- **datastream**
	- 作用：对指定buffer进行读写的模板类，比如往buffer中写入或读取 `int`、`double`、`string`、`vector` 类型的数据。提供类型序列化和反序列化的功能，包括内置类型，std容器，用户自定义类
	- 它的核心目标是：把 C++ 对象转换成字节流（序列化），以及把字节流恢复成 C++ 对象（反序列化）。
	- 成员：
		- `int _start;`  buffer的起始位置
		- `int _pos;`   当前处理的位置
		- `int _end;`    结束位置
	- 方法：
		- `写入方法`  `outstream << 123 << d << true << "string type";` 
		- `读出方法`  `insteam >> intValue >> floatValue >> boolValue >> stringValue;` 
	- 注意点：
		- 此类构造时要传入一个buffer对象
	- 参考：
		- wasm-chain  `datastream.hpp
