## 在linux 服务器上面运行代码 

出现  `QXcbConnection: Could not connect to display`  这样的错误

首先 
```bash
vim ~/.bashrc
```

然后在里面添加 
```typescript
export QT_QPA_PLATFORM='offscreen'
```

即时生效
```bash
source ~/.bashrc
```

这样就可以额
